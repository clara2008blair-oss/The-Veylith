# The Veylith

**The Veylith** is a dark-fantasy horror Minecraft Forge mod for Java Edition 1.20.1.

## Project status

The initial Forge project foundation is now in the repository. The next development stage is adding the Veylith creatures, items, world generation, structures, sounds, textures, and gameplay systems.

### Technical details
- Minecraft: 1.20.1
- Forge: 47.x
- Java: 17
- Mod ID: `veylith`
- Mod name: **The Veylith**

## Build

Generate the Forge Gradle wrapper with a compatible ForgeGradle setup, then use Java 17 and run the Gradle build task.
